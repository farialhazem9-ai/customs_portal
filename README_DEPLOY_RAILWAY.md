# Deployment Guide for Railway

This project is ready to deploy on Railway using Gunicorn.

## 1) Create a Railway project
- Go to https://railway.app
- Import the GitHub repository
- Select the project root

## 2) Add a database
- Add a MySQL database service in Railway
- Copy the generated connection values

## 3) Add environment variables
Add these values in Railway:

APP_SECRET_KEY=customs_portal_secret_2026
DB_HOST=your_railway_mysql_host
DB_PORT=3306
DB_USER=your_railway_mysql_user
DB_PASSWORD=your_railway_mysql_password
DB_NAME=railway
DB_CONNECTION_TIMEOUT=5
FLASK_DEBUG=0
PORT=10000

## 4) Start command
Use this command in Railway:

gunicorn app:app --bind 0.0.0.0:$PORT

## 5) Import database schema
After the app is deployed, import the SQL file:

- customs_portal.sql

## 6) Login credentials
Default system user:
- username: admin
- password: admin123

## 7) Important note
Do not use localhost in Railway.
Use the database host generated by Railway.
